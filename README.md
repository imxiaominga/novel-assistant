# Novel Forge · 小说世界推演

一个本地优先、单文件运行的小说世界观与剧情推演工具。通过「实体类型 + 自定义字段 + 实例 + 关系」组织设定，并结合地图轴、事件轴、角色成长阶段和章节大纲管理复杂故事。

> 当前仓库提供可直接运行的单文件网页版。项目数据保存在当前浏览器本地，AI 功能需要用户自行配置兼容 OpenAI Chat Completions 的接口。

## ✨ 核心功能

### 世界观与实体管理

- 自定义实体类型、字段与实例
- 内置角色、道具、势力、境界等常用类型
- 支持文本、数字、日期、单选、多选、图片及实体引用等字段
- 一对一、一对多、多对多类型关系
- 环形依赖与必填互锁检查

### 角色成长阶段

- 角色本体与成长阶段分层管理
- 分阶段记录年龄、状态、外貌、性格、能力、技能和战力
- 角色真名与别名全项目唯一校验
- 阶段时间范围及事件参与关系管理

### 地图与事件双轴推演

- 世界、国家、区域、城市、宗门、秘境等地图层级
- 地图状态期与势力归属变化
- 多世界线事件时间线
- 事件起因、经过、结果、影响及参与角色管理
- 可缩放、拖动、聚焦和折叠的地图剧情关系图

### 章节与正文

- 卷/章树状大纲
- 梗概、内容要点、角色、地图和事件关联
- 伏笔及回收状态管理
- 完整正文编辑与分页阅读
- 上一章、下一章快速切换

### 一致性检查

可发现或提示：

- 类型关系环形依赖
- 角色名称冲突、阶段时间重叠
- 事件早于角色出生时间
- 事件参与者未指定具体阶段
- 道具遗失或损毁后仍被使用
- 章节引用已死亡角色阶段
- 未回收伏笔
- 事件发生时地图缺少对应状态期

### AI 工作台

- 兼容 OpenAI Chat Completions 接口
- 从 TXT、Markdown、DOCX 中整理角色、地图、实体、事件与章节
- 支持章节创作、续写、场景生成、重写润色和情节大纲
- AI 姓名生成器
- 长文分段分析、进度显示与导入报告

## 🚀 快速开始

1. 下载仓库中的 `小说助手ai版.html`。
2. 使用现代浏览器打开该文件。
3. 创建项目并开始整理小说设定。
4. 如需 AI 功能，在「AI 工作台 → AI 接口配置」中填写接口地址、模型名称和 API Key。

应用为单文件版本，不需要安装 Node.js，也不需要后端服务器。除 AI 请求外，核心功能可在本地运行。

## 💾 数据与备份

- 项目数据保存在当前浏览器的 IndexedDB 中。
- AI 接口配置保存在当前浏览器的 localStorage 中。
- API Key 不会进入项目 JSON 备份。
- 清除站点数据、更换浏览器或更换打开方式，可能导致无法访问原有本地数据。
- 建议定期使用「导出备份」保存完整 JSON，并在需要时通过「导入备份」恢复。

## 🤖 AI 接口说明

应用调用 OpenAI 兼容的 Chat Completions 接口：

```text
POST {baseUrl}/chat/completions
```

模型服务需要允许浏览器跨域访问（CORS）。请仅在可信设备上保存 API Key，不要将包含密钥的截图、配置或浏览器数据提交到公开仓库。

## ⚠️ 使用说明

- `.docx` 可在浏览器中解析；旧版 `.doc` 请先转换为 `.docx`、`.txt` 或 Markdown。
- 刷新或关闭页面会中断正在执行的 AI 分析任务。
- 公共部署时，应由每位用户填写自己的 API Key。
- 本项目当前以桌面浏览器体验为主。
